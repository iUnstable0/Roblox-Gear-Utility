## Gears

This repo has every single ROBLOX gears with desc and other info in Gears-Detailed.json file.

there are also other random stuff i scraped like hats faces etc but the main focus is gears.

## Plugin

There is also a plugin (luau file) that can be used to load the gears into your game and fix them on the fly! (script manipulation)

- Fixes all deprecated modules like RBXxxx and LoadLibrary, and require() usage on the client
- Client sided insertService fixes coming soon
- Same as gear-specific fixes while keeping original functionality of the gear
- I might consider fixing Non-FE gears too but that would require a lot of time and effort soo..
